Privacy

The fitness dashboard at activities.laurencekellett.co.uk · updated 26 October 2026

This is a personal dashboard for one person, Laurence Kellett. It has no accounts, no sign-ups and no other users. Nothing here is sold, shared for advertising or used to train anything.

Google Calendar

The dashboard's server can add, move and remove events in its owner's own Google Calendar, so that a Zwift route planned in the dashboard shows as a private event, and dragging that event moves the plan back. It uses only the calendar.events permission, and it touches only the events it created itself, which it marks as its own. It never reads, changes or deletes any other event, and it never reads anyone else's calendar.

The access token Google grants is kept as an encrypted secret on the server (a Cloudflare Worker). It never reaches a browser and is not stored anywhere else. It can be revoked at any time from Google account permissions.

Activity and health data

Activities come from Strava, and health figures (sleep, heart rate, steps and the like) from Garmin, both for the owner only. Activities are shown publicly on the dashboard with GPS near home trimmed off. Health figures are never public: they are served only to a device holding an admin key, are not stored on the device, and are emailed only to the owner.
